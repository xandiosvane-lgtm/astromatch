# AstroMatch V8

V8 aggiunge due modalità:

1. **Trova il partner ideale**: richiede solo i dati della persona principale e
   costruisce un profilo astrologico target (Sole, Luna, Ascendente, Venere,
   Marte, asse 1/7 e case relazionali).
2. **Confronta candidati**: se vengono inserite persone reali, le classifica
   con sinastria e fattori di relazione.

Il profilo ideale è un modello interpretativo astrologico, non una probabilità
scientifica né l'identificazione di una persona reale.
